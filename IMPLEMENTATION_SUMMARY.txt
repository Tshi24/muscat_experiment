================================================================================
TELEMETRY STORED
================================================================================

Location: mission.true_SC{1}.software_SC_executive.store.charging

Fields (stored each timestep):
  • time_sec         - Simulation time [sec]
  • x_AU             - Heliocentric distance [AU] after clamping
  • isSunlit         - Boolean sunlight status
  • phiOff_pred      - Predicted potential with thruster OFF [V]
  • phiOn_pred       - Predicted potential with thruster ON [V]
  • phi_pred         - Predicted potential for current state [V]
  • thruster_is_on   - Input thruster state
  • thruster_cmd     - Commanded thruster state
  • reason_code      - Decision reason (string):
                       'NEGATIVE_THRESHOLD_ON'
                       'RECOVERY_OFF'
                       'HOLD'
                       'SUNLIGHT_POLICY_OFF'

HOW TO USE
================================================================================

1. Quick Status Check:
   >> cd /path/to/muscat_experiment
   >> check_charging_mitigation_status

2. Run DART Mission with Charging Mitigation:
   >> cd Mission
   >> Mission_DART
   >> cd ../Main
   >> main_v3

3. View Results After Simulation:
   >> charging = mission.true_SC{1}.software_SC_executive.store.charging;
   >> 
   >> % Plot predicted potential
   >> figure;
   >> plot(charging.time_sec, charging.phi_pred, 'k-', 'LineWidth', 2);
   >> xlabel('Time (sec)');
   >> ylabel('Spacecraft Potential (V)');
   >> title('Charging Mitigation - Predicted Potential');
   >> grid on;
   >>
   >> % Plot thruster commands
   >> figure;
   >> stairs(charging.time_sec, charging.thruster_cmd, 'b-', 'LineWidth', 2);
   >> xlabel('Time (sec)');
   >> ylabel('Thruster Command (ON=1, OFF=0)');
   >> title('EP Thruster Commands');
   >> ylim([-0.1, 1.1]);
   >> grid on;

4. Run Unit Tests:
   >> addpath(genpath('Supporting_Functions'));
   >> test_charging_mitigation_controller

5. Run Visualization Demo:
   >> cd Documentation
   >> example_charging_mitigation_visualization
